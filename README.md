# Reelcut

A link-first media converter for turning public video URLs into playable formats such as MP4, MKV, MP3, and WAV.

## Run it

Install the project dependencies, then start the app. The install downloads local copies of FFmpeg and yt-dlp, so system packages are not required:

```bash
npm install
npm start
```

Open `http://localhost:4173`. Paste a public link, select a format, and download the converted result. Only convert links you have permission to use, and follow the source site's terms.
